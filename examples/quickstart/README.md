# Quick Start

[`basic_ml.py`](basic_ml.py) is the shortest tour of three estimator styles:
supervised regression, dimensionality reduction, and clustering.

```bash
python -m pip install "mastermlx==0.1.15"
python examples/quickstart/basic_ml.py
```

The script demonstrates the standard `fit`, `predict`, and `transform`
interfaces without plotting dependencies. Continue with the
[`regression pipeline tutorial`](../regression/regression_pipeline.py) to add
train/test splitting, preprocessing, metrics, and nested parameters.

See the [`0.1.15 API guide`](../API_REFERENCE.md) for task-based imports.
